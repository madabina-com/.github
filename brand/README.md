### 📐 Usage Rules

**Clear space:** Leave 20% of logo height as empty space all around.

```
░░░░░░░░░░░░░░░░░
░               ░
░  [LOGO HERE]  ░
░               ░
░░░░░░░░░░░░░░░░░
```

**Minimum size:**
- Horizontal: 200px wide
- Icon only: 32x32px

**✅ Valid combinations:**
- Blue `#1E73E8` on White `#FFFFFF`
- White on Blue `#1E73E8`
- Blue on Light gray `#F9FAFB`

**❌ Forbidden:**
- Distort, stretch, rotate
- Change colors (e.g., green/red logo)
- Add shadow, outline, 3D effect
- Place blue on red or white on light gray (insufficient contrast)
- Use full logo at < 100px (use icon only)
