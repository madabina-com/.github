# Madabina · GitHub Organization

Welcome to the official **Madabina** GitHub organization.

Madabina is building a modern commerce platform for **Cash on Delivery e-commerce in Algeria**, helping merchants launch professional stores, manage orders, organize offers, and operate multiple brands from one ecosystem.
